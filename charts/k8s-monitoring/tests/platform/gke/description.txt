# GKE Standard

Standard [GKE](https://cloud.google.com/kubernetes-engine) clusters provide full access to worker nodes, while Google
manages the control plane, so the Kubernetes Monitoring chart runs with its normal configuration and no
platform-specific workarounds are required.

This test exercises the full feature set on GKE, including cost metrics gathered by OpenCost, which is configured to
read back from the metrics destination.
