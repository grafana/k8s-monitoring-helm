# EKS Add-on with Terraform

This test installs the Kubernetes Monitoring EKS add-on (`grafana-labs_kubernetes-monitoring`) the same way as the
`eks-addon` test, but provisions and manages the add-on with [Terraform](https://developer.hashicorp.com/terraform)
(see `addon.tf`) instead of the AWS CLI. This verifies that the add-on can be driven through infrastructure-as-code
tooling.

As with the plain add-on test, AWS renders and reconciles the chart inside the cluster, so these values are not
rendered locally (see the `.no-render` marker).
