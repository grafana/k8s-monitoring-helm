# Remote Configuration

This test configures the Alloy collectors to pull their configuration from Grafana Cloud
[Fleet Management](https://grafana.com/docs/grafana-cloud/send-data/fleet-management/) instead of relying solely on the
configuration generated by the chart. Each collector connects to the Fleet Management service with the remote
configuration settings applied through `collectorCommon`, verifying that remote config can be enabled across the
collectors the chart deploys.
